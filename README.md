# speedtest-cli

Консольный скрипт на Python для замера скорости скачивания. 
Скрипт делает 10 последовательных HTTP-запросов к указанному адресу, 
дожидается полного ответа на каждый запрос, а затем считает:
- среднее время одного запроса;
- суммарный объём скачанных данных;
- среднюю скорость скачивания.

## Требования

- Python 3.8+
- Внешние зависимости отсутствуют (используется только стандартная библиотека Python).

## Запуск

```bash
python speedtest.py <URL>
Для честного замера рекомендуется использовать ссылки на большие файлы
(видео, тяжелые картинки, установщики).

Пример запуска с реальным файлом:

bash
python speedtest.py https://www.python.org/ftp/python/3.11.5/python-3.11.5-amd64.exe

Единицы измерения
МБ/с — мебибайты в секунду (1 МБ = 1024 × 1024 байт).

Мбит/с — мегабиты в секунду (МБ/с × 8), для сравнения с тарифами провайдеров.

Скорость считается как суммарный объём / суммарное время по всем успешным
запросам — это устойчивее к случайным выбросам, чем среднее от
индивидуальных скоростей.

Особенности реализации
Чтение чанками: тело ответа считывается кусками по 64 КБ,
чтобы не загружать весь файл в оперативную память (важно для тяжелых файлов).

Обработка ошибок: если сервер вернет ошибку (например, 429 Too Many Requests)
или произойдет сбой сети, скрипт не упадет, а пропустит этот запрос,
подождет и продолжит работу. В итогах будет указано количество успешных попыток.

Паузы между запросами: для предотвращения блокировки со стороны сервера
между запросами выдерживается пауза в 1 секунду.

Таймаут: на один запрос выделяется 60 секунд (константа TIMEOUT_SEC в speedtest.py)
